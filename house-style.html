PHRASING PREFERENCES

Do not write "No meniscal tear identified." Write "No meniscal tear."

Do not write "No definite meniscal tear." Write "No meniscal tear."

Do not write "No vertebral fracture identified." Write "No vertebral fracture."

Do not write "No wedge fractures." Write "No vertebral fracture."

Do not write wedging, loss of height or compression deformity alone where appearances represent fracture. Write "vertebral fracture".
